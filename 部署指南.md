## Cost comparison

| Provider | Free tier | HTTPS | Custom domain | Bandwidth limit |
|---|---|---|---|---|
| GitHub Pages | 100 GB/month, 1 GB repo | Yes | Yes | Soft, 100 GB |

All three are free for personal use. Your PWA is ~45 KB total — even with heavy use you'll stay well within limits.

## Recommendation: GitHub Pages

1. You already have a GitHub account — zero registration.
2. Push to `github.com/liuq/ai-uk-teleprompter` → enable Pages in Settings → done.
3. URL will be `https://liuq.github.io/ai-uk-teleprompter/teleprompter.html`.
4. Custom domain (e.g. `tp.uk.ai`) supported later if desired.

## What you need to do

```
# 1. Create repo on GitHub: ai-uk-teleprompter (public or private)
# 2. In repo Settings → Pages → Source: "Deploy from a branch" → branch: main, folder: / (root) → Save
# 3. Push from your Mac:
cd ai-uk-teleprompter
git remote add origin git@github.com:liuq/ai-uk-teleprompter.git
git push -u origin main
# 4. Wait ~1 min, then open https://liuq.github.io/ai-uk-teleprompter/teleprompter.html
```

That's it. No config files needed — GitHub detects the static HTML and serves it with correct MIME types and HTTPS automatically.
